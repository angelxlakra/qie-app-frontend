# CLAUDE.md - QR Scanner App

This file provides guidance to Claude Code (claude.ai/code) when working on the **QR Scanner App** (gatekeeper app) for the blockchain-based event ticketing system on QIE Testnet.

## Project Overview

**This is the QR SCANNER APP** - a separate application used by gatekeepers at event venues to scan and redeem tickets. This app is **NOT** the main ticketing app (where users buy tickets).

**QR Scanner App Responsibilities:**
- Scan QR codes generated by ticket holders (from main app)
- Validate QR code data (expiry, signature, ticket ownership)
- Execute ticket redemption transactions (`redeemTicket`)
- Mint AccessPassNFT to users upon successful redemption
- Verify gatekeeper authorization
- Display redemption status and errors
- Optional: Verify AccessPassNFT ownership at additional checkpoints

**System Architecture Overview:**
- **Event Contract**: Where tickets are redeemed (ERC-1155 tickets → ERC-721 AccessPass)
- **AccessPassNFT**: ERC-721 tokens minted upon redemption, used for venue access
- **Gatekeeper**: Authorized wallet address that can call `redeemTicket()`
- **QR Code**: Contains EIP-712 signed message from ticket holder's wallet

**What This App Does NOT Do:**
- ❌ Event creation
- ❌ Ticket purchasing
- ❌ Marketplace trading
- ❌ QR code generation (that's done in the main app)

## Critical Implementation Patterns

### 1. QR Code Parsing Pattern

**QR codes from main app contain:**
```typescript
interface QRCodeData {
  e: string  // eventAddress
  h: string  // ticketHolder
  t: string  // tierId (as string)
  d: string  // deadline (as string)
  s: string  // signature (EIP-712)
}

interface ParsedQRData {
  eventAddress: `0x${string}`
  ticketHolder: `0x${string}`
  tierId: bigint
  deadline: bigint
  signature: `0x${string}`
}

function parseQRCode(qrString: string): ParsedQRData {
  const data = JSON.parse(qrString)

  return {
    eventAddress: data.e as `0x${string}`,
    ticketHolder: data.h as `0x${string}`,
    tierId: BigInt(data.t),
    deadline: BigInt(data.d),
    signature: data.s as `0x${string}`,
  }
}
```

### 2. Pre-Redemption Validation Pattern

**ALWAYS validate before calling redeemTicket:**

```typescript
import { EventABI } from './abis/Event.json'
import { createPublicClient, http } from 'viem'
import { qieTestnet } from './config/chains'

interface ValidationResult {
  valid: boolean
  error?: string
  ticketBalance?: bigint
  tierName?: string
}

async function validateRedemption(data: ParsedQRData): Promise<ValidationResult> {
  const publicClient = createPublicClient({
    chain: qieTestnet,
    transport: http(),
  })

  const now = BigInt(Math.floor(Date.now() / 1000))

  // 1. Check expiry
  if (data.deadline < now) {
    return {
      valid: false,
      error: 'QR code has expired. Ask user to generate a new one.',
    }
  }

  // 2. Check ticket ownership
  const balance = await publicClient.readContract({
    address: data.eventAddress,
    abi: EventABI,
    functionName: 'balanceOf',
    args: [data.ticketHolder, data.tierId],
  })

  if (balance === 0n) {
    return {
      valid: false,
      error: 'User does not own any tickets for this tier.',
    }
  }

  // 3. Get tier info for display
  const tier = await publicClient.readContract({
    address: data.eventAddress,
    abi: EventABI,
    functionName: 'getTier',
    args: [data.tierId],
  })

  return {
    valid: true,
    ticketBalance: balance,
    tierName: (tier as any).tierName,
  }
}
```

### 3. Gatekeeper Authorization Check Pattern

**Check gatekeeper status before attempting redemption:**

```typescript
async function checkGatekeeperStatus(
  eventAddress: `0x${string}`,
  gatekeeperAddress: `0x${string}`
): Promise<boolean> {
  const publicClient = createPublicClient({
    chain: qieTestnet,

}

// Use with wagmi hook
import { useAccount, useReadContract } from 'wagmi'

export function useGatekeeperStatus(eventAddress: `0x${string}`) {

```

### 4. Ticket Redemption Transaction Pattern

**Execute redemption with proper error handling:**

```typescript
import { useWriteContract, useWaitForTransactionReceipt } from 'wagmi'
import { parseEventLogs } from 'viem'

interface RedemptionResult {
  success: boolean
  transactionHash?: `0x${string}`
  accessPassId?: bigint
  error?: string
}

async function redeemTicket(data: ParsedQRData): Promise<RedemptionResult> {
  try {
    // 1. Validate first
    const validation = await validateRedemption(data)
    if (!validation.valid) {
      return { success: false, error: validation.error }
    }

    const walletClient = createWalletClient({
      chain: qieTestnet,
      transport: custom(window.ethereum),
    })

    const [gatekeeperAddress] = await walletClient.getAddresses()

    // 2. Check gatekeeper authorization
    const isGatekeeper = await checkGatekeeperStatus(
      data.eventAddress,
      gatekeeperAddress
    )

    if (!isGatekeeper) {
      return {
        success: false,
        error: 'Your wallet is not authorized as a gatekeeper.',
      }
    }

    // 3. Execute redemption
    const hash = await walletClient.writeContract({
      address: data.eventAddress,
      abi: EventABI,
      functionName: 'redeemTicket',
      args: [
        data.ticketHolder,
        data.tierId,
        data.deadline,
        data.signature,
      ],
      account: gatekeeperAddress,
    })

    // 4. Wait for confirmation
    const publicClient = createPublicClient({
      chain: qieTestnet,
      transport: http(),
    })

    const receipt = await publicClient.waitForTransactionReceipt({ hash })

    // 5. Extract AccessPassId from logs
    const logs = parseEventLogs({
      abi: EventABI,
      eventName: 'TicketRedeemed',
      logs: receipt.logs,
    })

    const accessPassId = logs[0]?.args?.accessPassId as bigint | undefined

    return {
      success: true,
      transactionHash: hash,
      accessPassId,
    }
  } catch (error: any) {
    return {
      success: false,
      error: parseRedemptionError(error),
    }
  }
}
```

### 5. QR Scanner Component Pattern

**Using html5-qrcode for scanning:**

```typescript
import { Html5QrcodeScanner } from 'html5-qrcode'
import { useEffect, useRef } from 'react'

interface QRScannerProps {
  onScan: (qrString: string) => void
  onError: (error: string) => void
}

export function QRScanner({ onScan, onError }: QRScannerProps) {
  const scannerRef = useRef<Html5QrcodeScanner | null>(null)

  useEffect(() => {
    const scanner = new Html5QrcodeScanner(
      'qr-reader',
      {
        fps: 10,
        qrbox: { width: 250, height: 250 },
      },
      false
    )

    scanner.render(
      (decodedText) => {
        onScan(decodedText)
        scanner.clear()
      },
      (errorMessage) => {
        // Ignore scanning errors (just means no QR code found yet)
      }
    )

    scannerRef.current = scanner

    return () => {
      scanner.clear()
    }
  }, [onScan, onError])

  return <div id="qr-reader" style={{ width: '100%' }} />
}
```

### 6. Complete Scanner Flow Component

```typescript
'use client'

import { useState } from 'react'
import { QRScanner } from './QRScanner'
import { useAccount } from 'wagmi'

interface Props {
  eventAddress: `0x${string}`
}

export function GatekeeperScannerApp({ eventAddress }: Props) {
  const { address, isConnected } = useAccount()
  const [state, setState] = useState<ScannerState>({ status: 'idle' })
  const [ticketInfo, setTicketInfo] = useState<any>(null)

  const handleQRScan = async (qrString: string) => {
    try {
      // Parse QR code
      const data = parseQRCode(qrString)

      // Verify correct event
      if (data.eventAddress.toLowerCase() !== eventAddress.toLowerCase()) {
        setState({
          status: 'error',
          message: 'QR code is for a different event',
        })
        return
      }

      setState({ status: 'validating', qrData: data })

      // Validate
      const validation = await validateRedemption(data)

      if (!validation.valid) {
        setState({ status: 'error', message: validation.error! })
        return
      }

      // Show confirmation
      setTicketInfo({
        holder: data.ticketHolder,
        tier: validation.tierName,
        balance: validation.ticketBalance,
        data,
      })
      setState({ status: 'confirming', ticketInfo: validation })
    } catch (err: any) {
      setState({ status: 'error', message: 'Invalid QR code format' })
    }
  }

  const confirmRedemption = async () => {
    if (!ticketInfo) return

    setState({ status: 'processing', transaction: '' })

    const result = await redeemTicket(ticketInfo.data)

    if (result.success) {
      setState({
        status: 'success',
        accessPassId: result.accessPassId!,
      })
    } else {
      setState({ status: 'error', message: result.error! })
    }

    setTicketInfo(null)
  }

  const resetScanner = () => {
    setState({ status: 'idle' })
    setTicketInfo(null)
  }

  if (!isConnected) {
    return (
      <div className="text-center p-8">
        <h2>Connect Gatekeeper Wallet</h2>
        <p>Please connect your authorized gatekeeper wallet to scan tickets.</p>
      </div>
    )
  }

  return (
    <div className="max-w-md mx-auto p-4">
      {state.status === 'idle' && (
        <div>
          <h2>Scan Ticket QR Code</h2>
          <QRScanner onScan={handleQRScan} onError={(e) => console.error(e)} />
        </div>
      )}

      {state.status === 'validating' && (
        <div className="text-center">
          <p>Validating ticket...</p>
        </div>
      )}

      {state.status === 'confirming' && ticketInfo && (
        <div className="card">
          <h3>Confirm Redemption</h3>
          <div className="space-y-2">
            <p>Holder: {ticketInfo.holder.slice(0, 10)}...</p>
            <p>Tier: {ticketInfo.tier}</p>
            <p>Tickets: {ticketInfo.balance?.toString()}</p>
          </div>
          <div className="flex gap-2 mt-4">
            <button onClick={confirmRedemption} className="btn-primary">
              Confirm Entry
            </button>
            <button onClick={resetScanner} className="btn-secondary">
              Cancel
            </button>
          </div>
        </div>
      )}

      {state.status === 'processing' && (
        <div className="text-center">
          <p>Processing redemption...</p>
        </div>
      )}

      {state.status === 'success' && (
        <div className="card bg-green-50">
          <h3 className="text-green-700">Entry Granted!</h3>
          <p>Access Pass ID: {state.accessPassId?.toString()}</p>
          <button onClick={resetScanner} className="btn-primary mt-4">
            Scan Next Ticket
          </button>
        </div>
      )}

      {state.status === 'error' && (
        <div className="card bg-red-50">
          <h3 className="text-red-700">Error</h3>
          <p>{state.message}</p>
          <button onClick={resetScanner} className="btn-primary mt-4">
            Try Again
          </button>
        </div>
      )}
    </div>
  )
}
```

## Common Gotchas

### 1. Camera Permissions
Always request camera permissions properly:

```typescript
// Check camera permissions before rendering scanner
async function checkCameraPermission(): Promise<boolean> {
  try {
    const stream = await navigator.mediaDevices.getUserMedia({ video: true })
    stream.getTracks().forEach(track => track.stop())
    return true
  } catch {
    return false
  }
}
```

### 2. QR Code Format Validation
Always validate QR code structure before parsing:

```typescript
function isValidQRFormat(qrString: string): boolean {
  try {
    const data = JSON.parse(qrString)
    return !!(data.e && data.h && data.t && data.d && data.s)
  } catch {
    return false
  }
}
```

### 3. Event Address Mismatch
Always verify the QR code is for the correct event:

```typescript
if (qrData.eventAddress.toLowerCase() !== selectedEvent.toLowerCase()) {
  throw new Error('QR code is for a different event')
}
```

### 4. Expired Signatures
Check deadline before calling contract:

```typescript
const now = BigInt(Math.floor(Date.now() / 1000))
if (qrData.deadline < now) {
  throw new Error('QR code has expired')
}
```

### 5. Gas Estimation Failures
Transaction will fail if:
- User no longer owns the ticket
- Signature is invalid
- Caller is not a gatekeeper
- Signature has expired

Always validate locally first to provide better error messages.

## Error Handling

### Error Reference Table

| Contract Error | Cause | User-Friendly Message |
|----------------|-------|----------------------|
| `SignatureExpired` | Deadline passed | "QR code has expired. Ask user to generate a new one." |
| `InvalidSignature` | Signature verification failed | "Invalid QR code. Please ask user to regenerate." |
| `InsufficientTickets` | User no longer owns ticket | "User no longer owns this ticket." |
| `NotGatekeeper` | Caller not authorized | "Your wallet is not authorized to redeem tickets." |
| `TierDoesNotExist` | Invalid tier ID | "Invalid ticket tier in QR code." |

### Error Parsing Function

```typescript
function parseRedemptionError(error: any): string {
  const errorMap: Record<string, string> = {
    SignatureExpired: 'QR code has expired. Ask user to generate a new one.',
    InvalidSignature: 'Invalid QR code. Please ask user to regenerate.',
    InsufficientTickets: 'User no longer owns this ticket.',
    NotGatekeeper: 'Your wallet is not authorized to redeem tickets.',
    TierDoesNotExist: 'Invalid ticket tier in QR code.',
  }

  for (const [key, message] of Object.entries(errorMap)) {
    if (error.message?.includes(key)) {
      return message
    }
  }

  return 'An unexpected error occurred. Please try again.'
}
```

## Security Considerations

### For Scanner App

1. **Verify gatekeeper status**: Always check `isGatekeeper` before attempting redemption
2. **Validate event address**: Ensure QR code is for the correct event
3. **Check expiry locally**: Don't waste gas on expired QR codes
4. **Secure wallet**: Gatekeeper wallet should be dedicated and secured
5. **Network verification**: Ensure connected to QIE Testnet (chain ID 1983)
6. **Rate limiting**: Implement cooldown between scans to prevent spam
7. **Transaction monitoring**: Log all redemptions for audit trail

### Data Privacy

1. **Don't log private keys**: Never log wallet private keys
2. **Minimize data collection**: Only collect what's needed for redemption
3. **Secure storage**: If caching data, encrypt sensitive information

## Performance Optimization

1. **Cache event data**: Fetch event/tier info once and cache locally
2. **Offline validation**: Validate QR expiry and format before any RPC calls
3. **Batch RPC calls**: Use `publicClient.multicall` for multiple reads
4. **Transaction queuing**: Handle network failures with retry logic
5. **Scanner optimization**: Use appropriate fps and qrbox size for scanner
